نام پروژه: نمایشگر و مبدل مدرن TIFF (Modern TIFF Viewer & Converter)

این پروژه یک نرم‌افزار دسکتاپ سبک، سریع و با ظاهری بسیار مدرن (Dark Mode) است که با استفاده از پایتون و کتابخانه‌های CustomTkinter و Pillow توسعه یافته است. این برنامه نه تنها برای مشاهده حرفه‌ای فایل‌های TIFF (به ویژه اسناد چندصفحه‌ای) طراحی شده، بلکه ابزارهایی برای مدیریت و ساخت این فایل‌ها نیز ارائه می‌دهد.

ویژگی‌های کلیدی:

رابط کاربری مدرن: طراحی تیره (Dark Theme) با نوارهای ابزار شناور و دکمه‌های گوشه‌گرد که هیچ مزاحمتی برای مشاهده سند ایجاد نمی‌کنند.

رندر با بالاترین کیفیت: تصاویر با رزولوشن اصلی و با استفاده از الگوریتم LANCZOS رندر می‌شوند تا متن‌ها در هنگام زوم تار نشوند.

کنترل پیشرفته زوم و جابه‌جایی: پشتیبانی از زوم با غلتک موس، جابه‌جایی با کلیک و کشیدن (Drag & Pan)، بازگشت به حالت فیت شدن در صفحه (FIT) و مشاهده سایز واقعی (1:1). برنامه حالت زوم شما را هنگام ورق زدن صفحات حفظ می‌کند.

ناوبری هوشمند: امکان ورق زدن صفحات یک فایل (Next/Prev Page) و همچنین پرش به فایل‌های بعدی و قبلی موجود در همان پوشه (Next/Prev File).

ثبت به عنوان برنامه پیش‌فرض ویندوز: با یک کلیک (دکمه MAKE DEFAULT)، برنامه به رجیستری ویندوز اضافه شده و می‌توانید فایل‌های TIFF را مستقیماً با دابل‌کلیک باز کنید.

تبدیل تصاویر به TIFF چندصفحه‌ای: ابزاری داخلی (CREATE TIFF) که به کاربر اجازه می‌دهد ده‌ها عکس با فرمت‌های مختلف (JPG, PNG و...) را انتخاب کرده و همه را در قالب یک فایل TIFF یکپارچه ذخیره کند.

Project Description (English) 🇬🇧
Project Name: Modern TIFF Viewer & Converter

This project is a lightweight, fast, and visually appealing desktop application built with Python using CustomTkinter and Pillow. It is designed not only for professional viewing of TIFF files (especially multi-page documents) but also provides built-in tools for managing and creating them.

Key Features:

Modern GUI: A sleek dark theme with floating, transparent toolbars and rounded buttons that maximize the viewing area.

High-Quality Rendering: Images are loaded at their original resolution and resized using the LANCZOS resampling filter to ensure crisp text and anti-aliased edges during zoom.

Advanced Zoom & Pan Controls: Scroll-wheel zooming, drag-to-pan functionality, 'Fit to Screen', and '1:1 Actual Size' viewing. The app remembers your zoom state across different pages.

Smart Navigation: Easily navigate through multi-page TIFFs or jump to the Next/Previous TIFF file in the current directory.

Windows OS Integration: A built-in "MAKE DEFAULT" button seamlessly registers the application in the Windows Registry, allowing users to open TIFF files via double-click or the "Open with" context menu.

Multi-page TIFF Creator: An integrated tool that allows users to select multiple image files (JPG, PNG, etc.) and convert them into a single, cohesive multi-page TIFF document
